
# Guess Number Game

A simple number guessing game developed using Python.

## Project Description

In this game, the computer generates a random number
between 1 and 100.

The player has 5 attempts to guess the correct number.

## Features

- Random number generation
- Limited attempts
- Smart hints
- Player ranking
- Input validation
- Replay option

## How to Run

Run the following command:

```bash
python guess_number.py
```
